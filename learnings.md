# Learnings

_Auto-maintained by LearningsManager. Do not hand-edit separators._

**Entry format** (3 lines per entry, separated by `---`):
```
YYYY-MM-DD | <task attempted>
OK: <what succeeded> | FAIL: <what failed>
RULE: <one hard rule to remember>  [HARD]  ← optional flag
```

`[HARD]` entries are never compressed and are always injected into agent context.
Entries that repeat the same failure ≥3 times are auto-promoted to `CLAUDE.md`.
